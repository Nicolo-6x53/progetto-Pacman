# Progetto Pacman - C# WPF

Autore: Nicolò Bianchi
Classe: 4^B Inf.

## Descrizione del Progetto
Questo progetto è una versione del classico gioco **Pacman** sviluppata in **C#** utilizzando il framework **WPF (Windows Presentation Foundation)** per l'interfaccia grafica.

## Funzionalit\u00e0 implementate
- [] Movimento del personaggio tramite i tasti freccia della tastiera.
- [] Gestione dei muri e delle collisioni.
- [ ] Punti e palline da raccogliere (in corso / completato).
- [ ] Intelligenza artificiale dei fantasmi (in corso / completato).

## Come avviare il progetto
1. Clona o scarica questo repository.
2. Apri il file della soluzione **`Pacman.sln`** con **Visual Studio**.
3. Assicurati di avere .NET installato.
4. Clicca sul pulsante **Avvia / Start** (o premi `F5`) per compilare ed eseguire il gioco.
